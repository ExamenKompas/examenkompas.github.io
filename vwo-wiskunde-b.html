Voorbeeldopgave · Analyse en functies

Een fabrikant ontwerpt een open bak met een vierkante bodem. De inhoud in liters wordt gemodelleerd door V(x) = 60x − x³ voor 0 < x < √60, waarbij x een maat in decimeters is.

Vraag

Bereken bij welke waarde van x de inhoud maximaal is. (4 punten)

Bekijk de uitwerking en puntenverdeling
  1. Differentieer: V'(x) = 60 − 3x². (1 punt)
  2. Stel V'(x) = 0: 60 − 3x² = 0, dus x² = 20. (1 punt)
  3. Omdat x positief is: x = √20 ≈ 4,47 dm. (1 punt)
  4. Controleer het maximum: V''(x) = −6x < 0 voor x > 0. (1 punt)

Tip voor deelpunten: Ook als je de maximale waarde niet vindt, leveren de afgeleide en de vergelijking V'(x)=0 vaak deelpunten op.

Zo bereid je je voor

Lees de context, noteer welke gegevens belangrijk zijn en schrijf je tussenstappen op. Controleer daarna je antwoord met de uitwerking. Een juiste aanpak kan ook punten opleveren wanneer het eindantwoord niet goed is.
